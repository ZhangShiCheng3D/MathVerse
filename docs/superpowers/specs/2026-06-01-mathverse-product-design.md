## 产品概述

**数界 MathVerse** 是一个覆盖小学到考研全学段的 AI 数学学习平台，定位为"能讲、能解、能伴你学数学的 AI"。三位一体：AI 数学老师（教）、AI 数学工具箱（解）、AI 数学学伴（伴）。

首发平台为微信小程序，核心技术基于 HKUDS/DeepTutor 的双循环多 Agent 架构。

- **产品名称**: 数界 MathVerse
- **Slogan**: 从一加一到高数，每一步都算数
- **品牌人格**: 专业但不傲慢、耐心但不啰嗦、了解你的学习
- **首发平台**: 微信小程序 → Web → 独立 App
- **商业模式**: Freemium + 订阅（免费版 10题/天，月卡 ¥29，季卡 ¥69，年卡 ¥199）

## 一、核心交互模型

### 1.1 首页结构（小程序 Tab Bar）

四个 Tab：🏠首页、🔍解题、📚学习、👤我的

首页作为总入口，露出三个核心场景 + 最近会话 + 今日推荐。

### 1.2 三入口职责边界

| 入口 | 看板 | 核心功能 | 用户心智 |
|------|------|---------|---------|
| 🔍 解题 | 拍照/输入 | 即问即解、多步推理、动画演示 | "帮我做这道题" |
| 📚 学习 | 知识地图 | 选学段→按章节学→AI讲解→练习 | "我要学这个知识点" |
| 👤 我的 | 数据仪表盘 | 错题本、学习记录、计划、估分 | "我学到哪了" |

### 1.3 关键设计原则

1. **零摩擦穿梭** — 解题中发现薄弱点，一键跳学习卡片；学习中例题不会做，一键切解题模式
2. **输入方式首选语音** — 小程序内长按说话输入数学题
3. **会话即记录** — 每次解题、每次学习都是对话，自动保存，可回溯
4. **统一悬浮AI助手** — 所有页面底部悬浮球，随时开启对话

## 二、三大入口详细设计

### 2.1 解题入口 🔍

输入方式（按优先级）：拍照 > 语音 > 文字

解题结果三层展示：
- 第1层：答案 + "怎么做的？"按钮（默认展开）
- 第2层：分步解析 — Step1/Step2/... 每步标注 WHY（点击展开）
- 第3层：总结 — 考察知识点、常见陷阱、同类题型（点击展开）

关键交互：
- 每步"为什么"按钮 → AI 解释这一步的原理
- "再来一道类似的" → 即时生成同类题
- 答错自动归入错题本；做对可手动收藏

### 2.2 学习入口 📚

知识地图：可缩放拖拽的知识树，纵向学段、横向依赖关系。节点颜色标记掌握度（绿/黄/灰/红）。

学习卡片四个动作：

| 动作 | 内容 | AI角色 |
|------|------|--------|
| 讲解 | AI口头讲解知识点，讲课风格 | 🧑‍🏫 老师 |
| 动画 | Manim 数学动画，30-90秒 | 🧑‍🏫 老师 |
| 例题 | 3-5道经典例题，可进入Deep Solve | 🔧 工具箱 |
| 练习 | AI生成配套练习 | 🔧 工具箱 + 🧭 学伴 |

讲课模式标准脚本：日常类比 → 数学定义 → 几何意义 → 典型例题 → 易错提醒

### 2.3 我的入口 👤

仪表盘核心模块：
- 连续打卡（GitHub热力图风格）
- 本周做题/累计做题/正确率
- 知识掌握雷达图（按学科维度）
- 今日计划（AI生成3-5项任务）
- 错题本入口（FSRS调度复习）
- 估分预测（考研模式专属）

## 三、内容 & 知识体系

### 3.1 知识图谱

全学段统一建模，五级结构：学段 → 学科 → 模块 → 章 → 知识点

| 学段 | 年级 | 模块数 | 知识点数 |
|------|------|--------|---------|
| 小学低段 | 1-3年级 | 4 | ~120 |
| 小学高段 | 4-6年级 | 5 | ~150 |
| 初中 | 7-9年级 | 7 | ~200 |
| 高中 | 10-12年级 | 8 | ~250 |
| 大学公共课 | 大一-大二 | 3 | ~120 |
| 大学专业课 | 大二-大四 | 4 | ~80 |
| 考研数学 | — | 3 | ~120 |
| 竞赛 | — | 5 | ~100 |

总计约 1,140 个知识点。每个知识点包含：ID、名称、别名、路径、考试标签、难度、前置依赖、子知识点、典型错误、教学策略。

### 3.2 内容生产策略

AI生成 + 人工审核，不搞人工建库。

| 内容类型 | 生产方式 | 审核要求 |
|---------|---------|---------|
| 知识点讲解文本 | AI生成→AI自检→专业审核 | 100% |
| 经典例题 | 公开题库+AI改编 | 抽检30% |
| 随堂练习 | AI自动生成 | AI自检 |
| 数学动画 | Manim模板+AI填充 | 关键帧预览 |
| 真题 | PDF导入→AI解析→入库 | 100%核对 |

冷启动策略：首发覆盖大学高数+考研数学（约240知识点），做深做透，其他学段按需求逐步扩展。

## 四、激励 & 留存 & 增长

### 4.1 学习激励体系

**短期（每日）**: 连续打卡热力图、每日3个随机任务、答题即时反馈动画

**中期（每周/每月）**: 周报推送、月度知识疆域点亮、青铜→王者升级系统

**长期**: 知识疆域全图、年度学习报告、估分变化曲线

**不做**: 焦虑营销、排行榜、断签惩罚

### 4.2 社交裂变

| 场景 | 裂变方式 |
|------|---------|
| 难题求助 | 转发题目卡片给微信好友 |
| 学习打卡 | 每日打卡海报→分享朋友圈/群 |
| 邀请有礼 | 双方各得3天VIP |
| 组队学习 | 3-5人小组互相看进度 |
| 知识对战 | 好友1v1抢答（娱乐向） |

### 4.3 付费转化

| 方案 | 价格 | 核心限制 |
|------|------|---------|
| 免费版 | ¥0 | 10题/天、基础解题、基础讲解 |
| 月卡 | ¥29/月 | 无限解题、完整Deep Solve、错题本 |
| 季卡 | ¥69/季 | 月卡全部+学习计划+估分 |
| 年卡 | ¥199/年 | 全部功能+Math Animator全集+优先新功能 |

关键转化时机：额度耗尽、错题暴增(>20题)、估分瞬间、动画预览

| Knowledge Hub (文档RAG) | — | 核心驱动 | — |

### 5.2 解题入口的 Deep Solve 增强

在 DeepTutor 原版分析循环 + 求解循环之前增加：

**第0层：题目理解**
- OCR/语音转文字
- 题目类型识别
- 学段自动匹配
- 关联知识点

输出格式改造为三层（答案→分步解析→总结），支持单步追问。

### 5.3 新增 AI 能力

| 能力 | 用途 | 实现路径 |
|------|------|---------|
| 数学OCR | 拍照识别手写公式 | MathPix API / LaTeX-OCR |
| 语音→LaTeX | 语音输入转公式 | LLM 转写 |
| 学段/知识点分类器 | 自动判断题目归属 | 知识图谱+LLM |
| 题目难度评估 | 自动评估难度1-5 | 知识点难度+步数+LLM |
| 错题分析引擎 | 提取错因类型 | LLM分析 |
| FSRS调度器 | 间隔复习算法 | 开源算法适配 |
| 蒙特卡洛估分 | 基于掌握度模拟考试 | 已有设计 |

### 5.4 LLM 策略

主要使用 DeepSeek V3（数学推理强、成本低），Qwen3 作为热备。简单追问等轻量级场景使用 Qwen3-32B。

## 六、数据飞轮 & 竞争壁垒

### 6.1 三层数据资产

| 层级 | 内容 | 形成 |
|------|------|------|
| 第1层 | 题目 & 解答数据 | 题目知识库 |
| 第2层 | 数学知识数据 | 学科认知模型 |
| 第3层 | 学习行为数据 | 个性化学习模型 |

### 6.2 三个不可复制的壁垒

1. **数学专用题库** — 用户真实提问（手写、截图、草稿），非爬虫公开题
2. **错因知识图谱** — 记录"为什么错"（哪一步推导错、哪条定理忘），需大量真实用户数据积累
3. **个性化学习轨迹** — 知识地图上的进展、卡点、有效节奏、匹配风格

### 6.3 产品成熟度分阶段目标

| 阶段 | 时间 | 目标 | 核心指标 |
|------|------|------|---------|
| 工具阶段 | 0-3个月 | "好用" | 次日留存>30%、日均解题>3次 |
| 平台阶段 | 3-9个月 | "离不开" | 月留存>40%、付费转化>5% |
| 生态阶段 | 9-18个月 | "无法替代" | 年留存>30%、NPS>50、自然增长>50% |

## 七、边界与约束

### 7.1 首发范围（v1.0 MVP）

- **覆盖学段**: 大学公共课（高数/线代/概率论）+ 考研数学（数一/二/三）
- **核心功能**: 解题 + 讲解 + 错题本 + 知识地图
- **平台**: 微信小程序
- **付费**: 免费版 + 月卡

### 7.2 明确的 No

- 不做 PvP 排行榜
- 不做直播课
- 不做社区/论坛
- 不做教师端/学校管理后台（v1阶段）
- 不覆盖数学以外的学科
- 不做AI批改主观题（如证明题全文批分）

### 7.3 关键风险

| 风险 | 应对 |
|------|------|
| AI输出数学错误 | CheckAgent验证 + "AI生成，仅供参考"标注 + 不确定时主动声明 |
| DeepSeek API不稳定 | Qwen3热备 |
| 大厂推出免费竞品 | 数据飞轮（用户积累的错题/进度无法迁移）+ 数学动画独特性 |
| 微信小程序审核 | 教育类目 + ICP备案 + 敏感词过滤 |
| 用户获取成本高 | 小程序社交裂变 + 打卡海报 + 邀请机制 |
