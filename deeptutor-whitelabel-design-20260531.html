1.2 核心架构 — 双循环多智能体系统

DeepTutor 的核心差异化和技术壁垒在于其 双循环多智能体架构，这也是白标产品最核心的价值承载层：

┌─────────────────────────────────────────────────────────┐ │ 用户输入 (Question) │ └──────────────────────┬──────────────────────────────────┘ │ ▼ ┌─────────────────────────────────────────────────────────┐ │ 📋 分析循环 (Analysis Loop) │ │ │ │ InvestigateAgent NoteAgent │ │ ├─ RAG 混合检索 ├─ 结构化笔记 │ │ ├─ 实时网络搜索 ├─ 知识提炼 │ │ ├─ 学术论文库查询 └─ 多源信息融合 │ │ └─ 知识图谱遍历 │ └──────────────────────┬──────────────────────────────────┘ │ 分析结果 ▼ ┌─────────────────────────────────────────────────────────┐ │ 🔧 求解循环 (Solve Loop) │ │ │ │ PlanAgent ──→ ManagerAgent ──→ SolveAgent ──→ CheckAgent │ │ 制定策略 协调执行 逐步求解 验证正确性 │ └──────────────────────┬──────────────────────────────────┘ │ 最终答案 + 引用 + 推理过程 ▼ ┌─────────────────────────────────────────────────────────┐ │ 格式化输出 (Formatted Output) │ │ Markdown + LaTeX + 代码高亮 + 引用标注 │ └─────────────────────────────────────────────────────────┘

1.3 六大功能模式

模式功能白标价值
Chat 自由对话，RAG增强。上传文档后基于文档内容问答 基础辅导场景，替代通用AI Chatbot
Deep Solve 多Agent协作逐步解题，含精确引用和推理链 数理化大题辅导，核心竞争力
Quiz Generation 从上传文档自动生成选择题/填空题/计算题/问答题 教师出题、学生自测，刚需功能
Deep Research 主题拆解→并行研究→结构化报告生成 论文辅助、深度专题学习
Math Animator 基于Manim生成数学概念动画（微积分/线性代数/几何） 高数/考研数学的视觉化学习
Visualize 交互式图表/知识图谱可视化 (Chart.js/SVG/HTML) 概念关系图、学习进度仪表盘

  • 内置记忆管理（短期+长期）

负责文档解析、向量化、混合检索：

1.5 Apache 2.0 协议意味着什么

你可以合法地：
  • ✅ 商业使用 — 直接卖钱，无需付费给HKUDS
  • ✅ 修改源码 — 改Logo、改UI、改功能、加模块
  • ✅ 私有部署 — 不需要公开你的修改
  • ✅ 重新分发 — 打包成你自己的产品
  • ✅ 商标自由 — 用你自己的品牌名称
你只需要：
  • 📋 保留原始LICENSE文件和版权声明（可以放在代码注释或关于页面）
  • 📋 修改过的文件加个notice说明改了哪里

这就是Apache 2.0被称为"商业最友好开源协议"的原因。

二、白标策略 — 五层定制模型

白标不是简单的"换个Logo"。DeepTutor的白标化需要在五个层级逐层定制，每一层的深度决定了产品的差异化程度：

白标深度金字塔

层级定制内容工作量差异化用户感知
L1 换皮 Logo、配色、名称、favicon 0.5天 无 "换了个皮肤"
L2 内容注入 预置知识库（真题/教材）、中文LLM切换、提示词本地化 3-5天 低 "里面的内容跟考试有关"
L3 体验改造 中国考试专用UI、学习路径引导、估分系统、微信登录 1-2周 中 "这个App就是为我做的"
L4 功能增强 错题本、智能组卷、学习计划生成、督学提醒、多端同步 2-4周 高 "这功能别家没有"
L5 生态闭环 自研内容体系、教师端后台、B端学校管理面板、API对外开放 2-3月 极高 "整个教学都用这个了"
MVP策略建议：首发走 L1+L2+L3部分，4周内上线。L4功能按用户反馈迭代追加。L5是B端变现通道，验证C端PMF后再投入。

3.2 为什么考研数学是首发最佳选择

  1. DeepTutor的Math Animator是独特武器：没有一个中国考研产品提供数学概念动画。DeepTutor基于Manim的Math Animator可以把极限、导数、积分、线性变换变成30秒动画——这是张宇讲课的核心吸引力（"画画讲题"），现在AI能做。
  2. Deep Solve模式天然适合数学大题：考研数学的大题（证明题、计算题）需要多步推理，DeepTutor的PlanAgent→SolveAgent→CheckAgent双循环架构恰好解决"学生不会做、看答案也不懂步骤"的痛点。
  3. 竞争真空：粉笔/中公有题库没AI推理，作业帮/小猿搜题面向K12不覆盖考研数学难度，ChatGPT/豆包能做但没有"不直接给答案"的教学设计。
  4. 付费意愿强：考研学生是付费意愿最强的教育用户群，¥199-499/年的定价已被验证（张宇全程班¥1000+）。
  5. 内容可获取：近10年考研数学真题公开，可批量导入DeepTutor Knowledge Hub做RAG底座。
